# Ringkasan identitas visual FlexiPay

Ringkasan ini merujuk pada PDF panduan brand yang tersimpan di folder ini.

- Warna utama: biru `#0959F8`, hijau `#2CCD55`, dan putih.
- Tipografi: Poppins Bold untuk judul dan Poppins reguler untuk teks.
- Logo utama: simbol F swoosh, wordmark FlexiPay, dan tagline “your payment, your flexibility”. Pertahankan proporsi aslinya.
- App icon: ikon tas FlexiPay pada bidang biru membulat; gunakan untuk ikon aplikasi/favicon.

Aset hasil ekstraksi dari panduan asli: `public/flexipay-primary-logo.png` dan `public/flexipay-app-icon.png`.
